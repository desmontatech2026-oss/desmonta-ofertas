# Desmonta Ofertas

Site de ofertas do Neto (Desmonta Tech): Shopee, Mercado Livre e Amazon, sempre com link de afiliado.

- `index.html`: o site (os dados das ofertas já vão dentro dele)
- `ofertas.json`: o catálogo completo
- `img/`: folhas de fotos dos produtos
- `robo/`: o robô que garimpa as ofertas 4x por dia (passo a passo em `robo/COMO-FUNCIONA.md`)
